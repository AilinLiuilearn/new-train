# 用户确认的当前主线设计：T

2026-11-17用户明确确认本版本作为当前研究主线。固定对应的代码、配置和第6轮EMA权重，后续变更按新的用户请求开展；这不是将网络参数设为冻结训练。

本轮数值达标的是文本条件T，而非带额外评分损失S。方法描述必须与所选权重保持一致。

## 实际图
CT ConvNeXtV2-Nano/PET MiT-B1 -> 原双侧对齐 -> 原M1分别增强并相加 -> 四尺度后置refiner -> 原GN decoder。

后置模块：L为当前尺度及DW3邻域表达；K来自相邻深层，S4为自身4x4汇聚。二者投影到32维。每尺度共享头得到两张任务驱动条件响应q；独立视觉内容分支只接收L/K，独立接纳分支只接收两张q。D/U不进入内容拼接。接纳权重乘候选视觉更新；固定BioMedCLIP向量和GAP候选内容产生32通道调制；1x1出口回写原特征，出口训练初始为零。输出形状不变。

固定文本Pulmonary tumor lesion.，冻结文本塔编码一次并缓存；推理只需要归一化CT/PET，无GT、专家decoder或文本塔。

## 实际训练目标
只有原BCE+Dice。T不含额外评分BCE、不含区域语义排序损失。两张q通过最终任务间接学习，不能写成校准前景概率或医学可靠性；共享头也不自动保证语义对齐。空间门不直接代表肿瘤概率，更新符号不等于补漏/去误检。

泛化及医学语义内容贡献未证明，性能增益不能替代必要机制对照。模型可以作为后续论文验证的保留候选，不是已经完成论文主张验证的最终结论。
