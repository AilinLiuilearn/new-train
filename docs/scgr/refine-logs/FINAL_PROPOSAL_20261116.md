# 后置评分条件细化：最终候选

## Problem Anchor
在不改M1和GN解码器结构的条件下，检验M1相加后的局部—上下文条件细化，是否减少轮廓附近FN/FP及远处FP；不预设深层一定正确，不压低基线，不以固定文本必然有效为前提。

## 数据依据与未知
历史M1第4轮EMA Dice78.3644%、HD9517.4866；121患者4514切片诊断：80.85%FN在GT内侧3px、49.71%FP在外侧3px、25.44%FP距GT>12px。同图常同时有FN/FP。这些是错误位置，不证明错误由相加抵消导致，也不证明粗尺度语义能修复。当前协议匹配M1参照是20261115重跑78.1551%/16.4411；两份参考不能混称同一个结果。

## 核心候选与范围
异构编码器(CT ConvNeXtV2-Nano、PET MiT-B1) -> 原双侧通道对齐 -> 原四尺度M1 -> 四尺度refiner -> 原GN decoder。只保留一个融合decoder，所有视觉参数训练，不加载历史分割/专家权重；编码器使用原通用预训练。SCGR仅为文件工作名，不宣称语义差异新概念已成立。

## 确定的算子
F1..4分别64/128/320/512通道。L=1x1/GN/GELU([F,DW3(F)])到32维；K0=1x1/GN/GELU(F_next)到32维，S4使用自身adaptive-average-pool到4x4。K为K0双线性插值。每尺度一个共享1x1前景评分头h，对L/K0调用两次。局部q=sigmoid(h(L))，上下文q在原生网格sigmoid再插值。

视觉内容V=3x3/GN/GELU([L,K])，输入仅64个视觉通道。空间接纳G=sigmoid(1x1(GELU(3x3([q_local,q_context]))))，2->8->1。没有D/U特征输入、硬错误标签或Tanh方向规则。D只记录诊断。

三组均保留相同通道调制MLP：g=2sigmoid(MLP([GAP(V),e]))，64->32->32；e=无bias线性投影(固定512文本条件)到32。V组条件为零；T/S为同一冻结归一化BioMedCLIP向量。F'=F+ZeroInit1x1(G*V*g)。末层weight/bias都为0，给定同一主干时初始完整输出与原M1逐元素相同，不保证训练后无损伤。

固定文本为Pulmonary tumor lesion.，严格加载本地BioMedCLIP训练文本塔(200 tensors)，缓存512维；训练/推理不运行文本塔。常量条件可被训练层吸收，动态输出不证明医学语义，不强行添加完整BioMedCLIP视觉塔。

## 监督与信息来源
V/T仅原BCE+Dice。S在此基础上加0.1 * score：八项原生网格BCEWithLogits(四尺度、两分支)的等权平均，GT用面积降采样软占比。空前景仍监督背景。GT只进入loss/metrics，不进入forward。S的分数得到直接监督，V/T只经最终任务间接学习。共享头与同GT定义都不保证概率校准，粗尺度混合会制造正常分歧，分数不是错误概率。没有另加区域语义排序或完整预测蒸馏。

## 创新与论文边界
候选主张是支持条件帮助上下文残差减少净错误；不是提出新减法、首次跨尺度融合或证明预训练医学语义。GN decoder本来有跨尺度处理，参数增加和普通上下文残差是重要替代解释。文本是可选支持贡献。当前三组只检验候选可用性、文本输入和新增评分损失的增量；仍缺容量匹配残差、去评分门及常量向量对照，不能凭三组结果完成顶刊顶会创新证明。

## 风险及反证
评分可能全背景或门控常量；记前景分数、均值方差、门幅度及AMP安全梯度。辅助损失可能干扰主任务；看T->S同轮最佳指标和错误分区。纯幅度收缩可能降低FP同时增加FN；必须同时报告两侧。仅门图变化或响应变亮不能算收益。语义内容无匹配向量对照，不声称已验证。
