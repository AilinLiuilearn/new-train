# BCSI-Adapt K50：独立的简化通道交互候选

本轮用户授权先实现并检验附件中的简化候选，随后明确将首组选择比例从25%改为50%。本轮运行完整E2一组，原M1同协议结果作为参照；不自动排B0/E1或随机路由对照。LPI-BI仍为用户放弃的候选，不恢复。

## 源码核对与适配边界

核验作者仓库 <https://github.com/taozh2017/BCSI>，提交 `3bbba85042cfc2bbe2a6f5ffedc5356c8946803d`。

- `model/Semi_MoE.py`：`mask_learner`是GAP、两层1×1卷积和ReLU/Softmax；`ChannelCrossAttention`包含Q/K/V线性投影和缩放点积注意力；`enhance_selected_channels`检索历史通道，增强后加回被选通道；原模型只在最深层训练路径执行交互。
- `trainer.py`：模型返回路由mask，但公开任务损失没有对该mask的可微选择监督；硬Top-K整数索引本身不提供评分梯度。
- `prediction.py`：推理传`is_training=False`，关闭原论文交互。该机制与本版训练/推理都参与的配对融合不同。
- 所核验公开树没有许可证文件，本版独立编写二维数学适配，不复制作者网络代码，不声称完整复现。原论文来源：Huang等，AAAI2026，<https://arxiv.org/abs/2601.05855>。

必要适配：当前配对CT/PET替代标注/未标注历史队列；四尺度替代仅最深层；8×8描述用于Q/K；源通道完整空间图作为V，未照搬原来的空间维V线性映射；推理持续启用；使用ST评分代理补足路由梯度。不加入SSP/伪标签/队列/文本/定位头/额外loss/Null/offset/残差门。

## 固定模型

CT ConvNeXtV2-Nano / PET MiT-B1 → 原双路对齐 → 四尺度BCSI-Adapt → 原M1 → 原GN单解码器。

四尺度64/128/320/512，分别选32/64/160/256个通道。两路独立GAP→Conv1×1(C,C/4)→ReLU→Conv1×1(C/4,C)。按分数稳定降序选择，保持原通道编号。

前向只取硬选择的50%通道；反向使用K倍Softmax作为ST替代权重，选中token与回写消息接受该权重的梯度。前向所有选中权重严格等于1，未选通道不修改；Softmax分母让未选评分也可收到梯度。这是离散排序的有偏代理，不声称Top-K索引本身可微。

Q/K描述由每个被选通道池化8×8、展开64维；两个方向各自Linear64→64的Q/K。注意力矩阵B×K×K，Softmax沿源通道轴；V保留源被选通道完整H×W，消息按接收方索引scatter加回。Q/K打分、Softmax与聚合FP32。

直接残差无额外alpha、无零出口，因此初始完整输出有意不同于原M1。不能声称初始输出恒等，也不能因预检通过声称该改动安全或有用。公共编码器、对齐、M1、GN初始化及后续loader RNG与原M1核对一致。

## 训练、评估与日志

- myenv；seed2023、512、batch16、AdamW8e-5/1e-4、原增强/余弦调度/EMA、最多60轮、连续3轮Dice未提升早停；仅best.pt实际选中权重。
- 只加载编码器通用预训练；全部任务模块从头，全部视觉参数更新。无历史分割、专家或LPI权重。
- 原BCE+Dice不变；一轮只做一次完整验证。新增小目标统计使用同一预测，不增加推理路径；按原验证Dice选best，HD95取同轮。
- 小目标描述固定为512图像中面积≤256像素的GT八连通二维分量：记录任意重叠、半覆盖召回及像素灵敏度。它们不是临床病灶或患者级检测，不参与选模，不能将该阈值解释为物理病灶大小。
- 记录选择频率、批内集合变化、与上次快照重叠、CT/PET独立评分梯度、通道注意力熵/Top1/16×16子矩阵、实际增量RMS、AMP和参数梯度。不同编码器的相同通道编号不代表相同语义；快照不能替代分割增益。
- 同协议M1参考为78.1551%/16.4411；更早78.8112或78.4970不是本轮同协议差值基准。单组不支持路由与交互分别有效，更不能凭失败排除原BCSI在其原任务中的机制。

## 实现与运行

代码：`variants/bcsi_adapt/`；配置`configs/bcsi_adapt.json`；预检`scripts/bcsi_adapt_preflight.py`与`docs/BCSI_ADAPT_GPU_PREFLIGHT.json`。

```bash
bash scripts/myenv.sh scripts/run_single.py --campaign bcsi_adapt_k50_20261116 --gpu 0
```

提交并推送协同分支后，在固定提交的独立worktree执行。运行器只启动一个full组，支持STOP，并自动汇总同轮指标；没有后续实验队列。预检临时权重全部丢弃，正式重新从头初始化。仅每5轮或用户询问、异常时人工查看。

## 已完成核验

37项CPU测试通过；独立只读审查未发现工程阻塞。真实512/batch16三次仅任务BCE+Dice的AMP更新通过，选中及未选路由评分均有梯度，两方向Q/K及路由器均有参数梯度；best-only权重加载严格一致。公共初始化及后续CPU RNG一致。

完整模型43,966,993参数，新前置模块454,144参数。包含优化器和EMA时GPU峰值分配约15.25GiB，保留约16.29GiB。

初始eval模式对齐层尚无数据运行统计，CT/PET幅度相差大：PET第三尺度相对更新约70.91。首次真实训练前向中两路输入RMS均约0.70，更新比例约0.411–0.475；第三次更新约0.370–0.494。因此不能把eval初始比值解释为训练70倍扰动。约四至五成的实际残差仍是待观察风险，不等于轻微修改。所有预检权重丢弃，正式训练重新初始化；预检不是性能或长期稳定性证据。
